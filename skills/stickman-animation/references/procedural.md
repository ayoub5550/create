# الطبقات الإجرائية (procedural) — كلها دوالّ نقيّة لـ t

مرجع للمهارة `stickman-animation`. الشرط الدائم: أيّ إطار يُحسب وحده بأيّ ترتيب. ما يحتاج محاكاة يُحسب **مسبقاً** عند التهيئة ويُخزّن.

## 1. IK بعظمتين (two-bone IK) لتثبيت اليد والقدم
المدخلات: الجذر R (كتف/ورك)، الهدف T، طولا العظمتين a وb.
```js
function ik2(R, T, a, b, bendSign) {
  const dx = T.x - R.x, dy = T.y - R.y;
  const d = Math.min(Math.max(Math.hypot(dx, dy), 1e-3), a + b - 1e-3);
  const alpha = Math.acos((a*a + d*d - b*b) / (2*a*d));
  const base = Math.atan2(dy, dx);
  const ang = base + bendSign * alpha;            // bendSign يحدّد جهة انثناء المرفق/الركبة
  return { x: R.x + a*Math.cos(ang), y: R.y + a*Math.sin(ang) };   // المرفق أو الركبة
}
```
- الركبة تنثني دائماً **للأمام** بالنسبة لاتجاه الشخصية؛ المرفق للخلف/للأسفل غالباً.
- الاستعمال: يد على كتف شخصية أخرى، إشارة إلى نقطة، مصافحة، قدم على درجة.

## 2. تثبيت القدم (foot lock)
- التلامس: ارتفاع القدم < ~2٪ من طول الشخصية وسرعتها صغيرة.
- أثناء التلامس: خزّن موضع القدم عند بداية التلامس، وحلّ IK الساق إليه.
- الحوض: من الموكاب مع تصحيح بمتوسّط خطأ التثبيت.
- الإفلات: وزن IK من 1 إلى 0 خلال 0.10–0.15 ث.
- لأن بداية التلامس تُعرف من المقطع نفسه، احسب جدول فترات التلامس مسبقاً لكل مقطع، فيبقى الإطار دالّة لـ t.

## 3. الدمج بالقصور الذاتي (inertialization)
للانتقال من مقطع إلى آخر دون تشغيل الاثنين معاً:
- عند لحظة التبديل t0: الفارق `x0 = prev − next` لكل زاوية، وسرعته `v0`.
- `off(dt) = (x0 + (v0 + x0*w)*dt) * Math.exp(-w*dt)` حيث `w = 2/halflife` و`halflife ≈ 0.1–0.2 ث` و`dt = t − t0`.
- الوضعية = المقطع الجديد + off. حتمي تماماً لأن x0 وv0 يُحسبان من المقطعين عند t0.
- البديل الأبسط: `M.pose(J, spec, w)` بوزن متدرّج (crossfade) 0.2–0.4 ث.

## 4. النوابض والحركة الثانوية (springs)
- **صيغة مغلقة:** زاوية الطرف الثانوي = نابض مخمّد يستجيب لسرعة الأب؛ قرّبها بجمع على آخر N إطارات (N ≈ 12) من حركة الأب. لا حالة.
- **سلسلة Verlet (وشاح، شعر):** حاكِ **عند التهيئة** بخطوة ثابتة 1/120 ث على كامل مدّة المشهد، وخزّن المواضع، ثم اقرأها بـ t
  (استيفاء بين أقرب عيّنتين). الرابط 0 مثبّت بالرقبة، و2–3 تكرارات لقيود المسافة.
- لا تحاكِ إطاراً بإطار أثناء الريندر: العمّال يقفزون بين الإطارات.

## 5. التنفّس والخمول (breathing / idle)
- الصدر: `scaleY = 1 + 0.015*sin(2π t / 3.5)` تقريباً (هادئ)؛ أسرع عند الانفعال. الكتفان يرتفعان ~1 بكسل مع نفس الإشارة.
- التمايل: ضجيج أحادي البعد `noise(t*0.3 + seed) * 2°`.
- انزياح الوزن كل 4–8 ث، مبذور لكل شخصية.
- `Talk.idle(J, t, seed)` يجمع ذلك بطور مختلف لكل شخصية.

## 6. الرمش (blink)
- أزمنة من مولّد مبذور: `StickFilm.u.blinks(seed, t0, t1, {min, max})`؛ قاعدة عملية: فاصل 2–6 ث، لا أقلّ من 1.5 ث.
- المدّة 3–4 إطارات. أضف رمشة عند الالتفاتات الكبيرة ونهايات الجمل.
- البذرة من معرّف الشخصية، فلا يرمش اثنان معاً.

## 7. النظر (gaze / look-at)
- زاوية الرأس = `clamp(atan2(target − head), ±35°)`، والعين تسبق الرأس ~80 ms، والرأس يلحق بنابض halflife ≈ 0.15 ث.
- في الحوار: المستمعون ينظرون إلى المتكلّم؛ المتكلّم يشيح أحياناً وهو يفكّر ثم يعود في نهاية الجملة.
- الهدف يأتي من `resolve(id, t)` أو من موضع رأس الشخصية الأخرى.

## 8. الإيماءات المصاحبة للكلام
- توقيت الكلمات من `tts.json`/`timeline.json`.
- الضربة على بداية الكلمة المشدّدة، والتحضير قبلها بـ 200–300 ms، والارتداد بعد 0.4–0.8 ث صمت.
- السعة = `personality.energy` من `cast.json` × غلاف الجهارة.
- جدول `Talk.act`: `[{g:"explain", t0, t1, amp, side, ease}]`؛ `Talk.accents(J, t, times, amp)` لهزّة الرأس على المقاطع المشدّدة؛
  `Talk.nods(J, t, times, amp)` للمستمع.
- طبقة أساس اختيارية: ذراعا مقطع CMU «حديث وشرح بالإيماءات» (الموضوعان 18/19) ببداية مبذورة، والإيماءات القاعدية فوقه.

## 9. مزامنة الشفاه
- `tools/voice/lipsync.py` يخرج إشارات Rhubarb (`A`..`H`، `X`) مع قواعد عربية: م/ب ← فم مغلق، ف ← شفة على الأسنان، و/ضمّة ← استدارة.
- تقديم 1–2 إطار، وثبات ≥ 2 إطار. `film_data.js` (`C.mouth`) ← `Talk.mouth(C.mouth)` ← خيار `mouth` في `StickFilm.rig`.

## 10. ترتيب الرسم
- الشخصيات حسب العمق (y القدمين أو `z` صريح).
- داخل الشخصية: الطرفان البعيدان ← الجذع والرأس ← الطرفان القريبان. للمصافحة: تجاوز مؤقّت للترتيب خلال [t0, t1].
