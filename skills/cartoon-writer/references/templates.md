# قوالب الكتابة

مرجع للمهارة `cartoon-writer`. انسخ القالب واملأه، ثم احذف ما لا يلزم.

## 1. عمود القصة (story spine) — فيلم قصير 1–3 دقائق
```
كان يا ما كان …                 (العالم والشخصية في سطر)
وكلّ يوم …                       (العادة / الوضع الطبيعي)
حتى جاء يوم …                    (الحدث المحرّك — في أول 10–20٪)
وبسبب ذلك …                      (المحاولة 1)
وبسبب ذلك …                      (المحاولة 2، أصعب)
وبسبب ذلك …                      (المحاولة 3 تكسر النمط)
إلى أن أخيراً …                  (الذروة / التحوّل)
ومنذ ذلك اليوم …                 (العالم الجديد + الختمة)
```
تقسيم زمني عملي لفيلم 90 ث: خطّاف 0–8 ث، رغبة حتى ~18 ث، ثلاث محاولات حتى ~70 ث، ذروة ~80 ث، ختمة حتى النهاية.

## 2. حلقة 7–11 دقيقة
| القسم | المدّة التقريبية | ما يحدث |
|---|---|---|
| افتتاحية باردة (cold open) | 30–60 ث | نكتة أو صورة محرّكة تطرح السؤال |
| العنوان | 5–10 ث | — |
| الفصل الأول | ~3–4 د | المشكلة، القواعد، رغبة البطل، بدء قصة B |
| كسر الفصل (act break) | في المنتصف تقريباً | انقلاب أو تشويق |
| الفصل الثاني | ~3–4 د | تصعيد إلى أكبر مشهد؛ قصة B تصطدم بـ A |
| الحلّ | ~30–60 ث | سريع |
| الذيل (tag) | 10–30 ث | نكتة أخيرة أو تذكير بالافتتاحية |

جدول القصّتين:
```
A (تقود):  …  …  …  [ذروة]
B (تعكس):    …    …  [تصطدم بـ A] → تغذّي الحلّ
```

## 3. بطاقة شخصية (تُنقل إلى cast.json)
```
الاسم:        …         المعرّف: …   (ascii، يُستعمل في كل الملفات)
الرغبة:       …         الحاجة: …     العيب: …
طريقة الكلام: جمل قصيرة/طويلة، فصحى/لهجة …، لازمة: «…»
الحركة:       طاقة 0.5–1.5، إيماءة مفضّلة: explain/shrug/…
```

## 4. ورقة النبضات (beat sheet)
| # | النبضة (ما يتغيّر) | ما يُرى | ما يُقال | من | عاطفة |
|---|---|---|---|---|---|
| 1 | سليم يجد الصندوق | WS سليم يتعثّر | — | — | فضول |
| 2 | يريد فتحه | MS يدان على الغطاء | «لنرَ ما فيك.» | salim | حماس |
| 3 | هدى تمنعه | دخول هدى من اليمين | «لا تفتحه!» | huda | خوف |

## 5. من النص إلى `scene.json`
```json
{"lines":[
 {"id":"l01","who":"salim","text":"لنرَ ما فيك.","emotion":"excited","gap":0.3},
 {"id":"l02","who":"huda","text":"لا تفتحه!","emotion":"afraid","gap":0.2},
 {"id":"l03","who":"salim","text":"ولمَ لا؟","emotion":"curious","gap":0.8},
 {"id":"l04","who":"huda","text":"لأنه صندوقي.","emotion":"deadpan","gap":0.4}
]}
```
لاحظ: `gap` 0.8 قبل سطر الضربة (وقفة قبل النكتة)، والتشكيل فقط حيث يلتبس النطق («لنرَ»، «لمَ»).

## 6. فحص الحوار
- كل سطر ≤ 12 كلمة؟ احسبها.
- اقرأه بصوت: هل يُقال في نفَس واحد؟
- احذف الأسماء: هل تعرف القائل؟
- اشطب كل سطر تقوله الصورة. ثم اشطب سطراً آخر.
- هل في المشهد نصّ تحتي: ما يريده كلّ منهما ولا يقوله؟

## 7. من النص إلى الأنيماتيك
```
script / beat sheet → scene.json + cast.json
→ python tools/voice/dialogue.py films/<slug>
→ python tools/direct/shotlist.py auto films/<slug>
→ (مهارة film-director: إخراج يدوي) → shotlist.py check
→ صفحة بوضعيات ثابتة + الصوت → tools/render/snap.py → مراجعة
→ التحريك الكامل
```
في المراجعة اسأل: هل القصة مفهومة بلا موسيقى ولا تحريك؟ إن لم تكن، فالمشكلة في النص لا في الرسوم.

## 8. نصائح الكتابة بالعربية
- فصحى طبيعية معاصرة؛ تجنّب الألفاظ المعجمية النادرة في الحوار.
- لهجة لكل شخصية إن أردت (مصرية، شامية، خليجية، مغاربية…)، وثابتة طوال الفيلم، ومتّسقة مع صوت TTS المختار.
- تشكيل جزئي على ما يلتبس فقط: الأفعال المبنيّة للمجهول، والأسماء النادرة، وما يخطئ فيه المحرّك بعد `stt_check.py`.
- الأرقام بالكلمات إن كان نطقها مهمّاً.
- علامات الترقيم توجّه الأداء: «؟» ترفع النبرة، «…» وقفة، «!» شدّة.
