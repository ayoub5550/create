# «البذرة» — فيلم ستيكمان (60 ث، 16:9)
رجل متعب يجد بذرة في أرض عطشى، فيزرعها وينتظر الليل والبرد والمطر، ثم تصير شجرة يجلس في ظلّها.
«ما تزرعُهُ اليومَ يُظلِّلُكَ غداً». النتيجة: [`gallery/albidhra.mp4`](../../gallery/albidhra.mp4)

| ملف | الدور |
|---|---|
| `script.json` / `tts.json` | النص وتوقيتات الصوت (ElevenLabs «George»). السطر s4 مقسوم إلى `s4a` و`s4b` عند 2.54 ث |
| `clips.json` → `film_clips.js` | 6 حركات من CMU: مشي حزين، التقاط، حفر، زرع، جلوس، فرح |
| `film.js` | الفيلم: المقاطع، وطبقات التمثيل، والوجه، والعالم، والكاميرا، والإضاءة |
| `score.py` | حجاز ← نهاوند ← عجم، مع مطر ورعد وعصافير وخطوات |
| `build.sh` | يعيد البناء إلى `proj/` |
