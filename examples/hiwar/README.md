# «حوار» — فيلم حواري: شخصيتان تتكلّمان (29 ث، 16:9)
تتمّة «البذرة»: سامي زرع بذرة **أمس** ويستغرب أنها لم تنبت. ليلى: «الشجرة تحتاج وقتاً». هو: «كم؟ ساعة؟ ساعتين؟»… وقفة…
هي: «سنوات.» يصدم، ثم يعاند: «إذن… سأنتظر هنا»، ويجلس على الصخرة خلفه مواجهاً التلّة، وليلى تضع يدها على عينيها… فتنبت
النبتة بينهما، ثم دائرة الختام ومؤثّر موسيقي وبطاقة العنوان.
النتيجة: [`gallery/hiwar.mp4`](../../gallery/hiwar.mp4)

| ملف | الدور |
|---|---|
| `cast.json` | الطاقم: سامي (أحمر، وشاح وخصلة شعر، `ar-SA-HamedNeural +10% +2Hz`)، ليلى (أزرق مخضرّ، حجاب، `ar-SA-ZariyahNeural -4%`) |
| `scene.json` | النص: 5 أسطر بفجوات مقصودة (1.35 ث قبل «سنوات.»، 1.6 ث بعد الصدمة)، `max_pause` يقصّر سكتات TTS داخل السطر، و`key`/`react`/`wide` للإخراج |
| `shots.json` | المونتاج اليدوي: 11 لقطة بأزمنة مربوطة بالكلمات (`"l4.end-0.1"`)، مع `zoom`/`top`/`frameAt`/`shake`، يُفحص بـ `shotlist.py check` |
| `clips.json` → `film_clips.js` | حركة من CMU: الجلوس (13_01)؛ والمشي (82_10) محفوظ للنسخ القادمة |
| `film.js` | التمثيل: جداول الإيماءات على الكلمات، قاعدة الثلاث بالجسد، الشهقة والرمشة المزدوجة، لطمة الجبين بيد مفتوحة، الكاميرا، دائرة الختام، العنوان |
| `score.py` | عجم تحت الكلام، صمت (مع صرصور خافت) قبل النكتة، شهقة وضربة على ردّ الفعل، نهاوند للعناد، ارتطام الجلوس وصفعة الجبين، فرقعة وأجراس للنبتة، مؤثّر عند إغلاق الدائرة؛ ماستر −15 LUFS |
| مولَّدة | `assets/voice/*.mp3`، `tts.json`، `timeline.json`، `lipsync.json`، `film_data.js` (من `tools/voice/dialogue.py`) |
| `build.sh` | الأصوات (مخزّنة) ← الشفاه ← فحص اللقطات ← الموسيقى ← `proj/` |

```bash
bash examples/hiwar/build.sh                 # يعيد البناء (لا يعيد صوتاً لم يتغيّر نصّه)
bash examples/hiwar/build.sh --shots         # قائمة لقطات تلقائية بدل اليدوية (تمسح التعديلات اليدوية)
python tools/render/snap.py examples/hiwar/proj sheet.png --every 1
bash tools/render/render.sh examples/hiwar/proj out/hiwar.mp4
python tools/voice/captions.py examples/hiwar/tts.json examples/hiwar/timeline.json out/hiwar.srt --speakers examples/hiwar/cast.json
python tools/render/model_sheet.py examples/hiwar/cast.json out/hiwar_cast.png   # ورقة نموذج الطاقم
```

## ماذا تتعلّم منه
- **الصوت هو الساعة:** كل زمن في `film.js` و`score.py` يُحسب من `timeline.json` بنفس الصيغ (`tSit = L5.end + 0.15`،
  `tSprout = tSit + 4.15`)، فإعادة التسجيل أو تغيير `gap` لا يكسر شيئاً.
- **التوزيع على المسرح يخدم النكتة:** التلّة **بين** الشخصيتين والصخرة خلف سامي، فيجلس دون أن يعبرها، وتظهر النبتة وردّا
  الفعل في لقطة ثنائية واحدة قريبة (في المسودة 2 كانت القفلة في لقطة واسعة جداً فلم تُقرأ).
- **الإخراج:** MCU للنداء (الخطّاف) ← WS تأسيسية ← MCU ← MS ← قطع إلى «هاه؟» على آخر مقطع ← قاعدة الثلاث مع اقتراب بطيء
  ← CU للسطر المفتاح ← CU لردّ الفعل مع اهتزاز ← MCU بذراعين مكتوفتين ← WS يجلس (قطع على الحركة) ← MCU للطمة الجبين
  ← نفس الـ WS للقفلة (`frameAt`) ← iris يغلق على سامي والنبتة، يثبت ثانية، ثم العنوان.
- **الكوميديا:** قاعدة الثلاث (هزّ كتفين ← يد ← يدان)، الوقفة الصامتة مع رمشة بطيئة، ردّ الفعل الطويل، القفلة بالصورة.
- المهارات: `skills/talking-characters`، `skills/film-director`، `skills/film-editor`.
