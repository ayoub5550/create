# خريطة الأدوات: ماذا يوجد في العالم، ومتى تستعمله، وإلى أين نتطوّر

> بحث بتاريخ 2026-10-23. الأرقام والتراخيص تتغيّر، فتحقّق من صفحة كل مشروع قبل الاعتماد عليه.
> القاعدة: نستعير **الأفكار** بحرية، أمّا **الكود** فلا نأخذه إلا بترخيص متساهل (MIT / Apache / BSD)، ونذكره في `THIRD_PARTY.md`.

## محرّكات الفيديو بالكود (HTML / React / Python → MP4)
| الأداة | الفكرة | متى تستعملها |
|---|---|---|
| **HyperFrames** (`heygen-com/hyperframes`) | HTML + GSAP، ويصدّر بالقفز إلى كل إطار | **محرّكنا الحالي**: صفحة واحدة، والمعاينة بالمتصفّح، والتصدير سريع |
| Remotion | مكوّنات React، ولكل إطار `useCurrentFrame()` | مشاريع React كبيرة. **راجع ترخيصه** (مجاني للأفراد والفرق الصغيرة فقط) |
| Motion Canvas / Revideo | مشاهد TypeScript بمولّدات، وRevideo للتصدير على خادم | رسوم توضيحية دقيقة التوقيت |
| Manim | رياضيات وفيزياء بـ Python | المعادلات والرسوم البيانية المتحرّكة (Code2Video يعتمد عليه) |
| Lottie / Rive | رسوم متجهية تفاعلية | عناصر واجهة وأيقونات متحرّكة داخل الفيلم |

محرّكنا (`engine/stickfilm.js`) لا يرتبط بـ HyperFrames: أيّ مشغّل يستدعي `render(t)` لكل إطار يكفي.
لذلك يمكن نقله إلى Remotion بمكوّن صغير.

## وكلاء ومصانع أفلام مفتوحة
| المشروع | ماذا نأخذ منه |
|---|---|
| OpenMontage (`calesthio/OpenMontage`, **AGPL**) | أوّل مصدر استلهمنا منه (Ink Theater). **لا ننسخ منه كوداً** بسبب AGPL، وكتبنا محرّكنا من الصفر |
| stickman-kino (`dsauce/stickman-kino`, MIT) | مكتبة وضعيات وأدوات وانتقالات للستيكمان: مصدر جيّد لتوسيع الدعائم |
| stix (`bassimeledath/stix`) | «الأصول أولاً»: شخصيات وخلفيات SVG تُبنى مرّة وتُعاد في كل مشهد للحفاظ على الاتّساق |
| stickman-video-director (`kaomei`, MIT) | خطط إخراج ونصوص لفيديو دقيقة (موجّه لنماذج الفيديو، لا للكود) |
| Code2Video (`showlab/Code2Video`) | **ناقد بصري** يقيس المواضع على شبكة 6×6 ويصلح التداخل: الفكرة وراء بوّابة الناقد عندنا |
| MovieAgent، FilmAgent، AniMaker | تخطيط متعدّد الوكلاء (مخرج، كاتب، مصوّر)، واختيار الأفضل من N |
| MotionLoom، Rev2D (MIT) | مهارات للوكلاء للتحريك. Rev2D يحرّك شخصيات 2D بهيكل JSON ويوفّر خادم MCP |
| AnimatedDrawings (Meta) | يحرّك رسمة طفل بهيكل عظمي: طريق ممكن لشخصيات مرسومة بدل الستيكمان |

## الحركة (Motion)
| الأداة | الحالة |
|---|---|
| **CMU MoCap** | **مستعملة الآن**: أكثر من 2600 لقطة حقيقية، مجانية لكل استعمال (`tools/mocap/`) |
| HY-Motion 1.0 (Tencent) | نصّ → حركة 3D. جرّبناه عبر HF Space `tencent/HY-Motion-1.0` (`/generate_motion_func`) ونجح في نحو 9 ث، لكنّ حصّة GPU المجانية تنفد بعد طلب واحد، فيلزم `HF_TOKEN`. يخرج FBX، والتحويل المقترح: Blender ← BVH ← `bvh2clip.py` |
| Kimodo (NVIDIA, Apache-2.0) | نصّ + قيود (مسار، نقاط، وضعيات مفتاحية) → حركة. الـ Space كان متوقّفاً عند التجربة |
| ARDY، MoMask، MotionGPT | توليد طويل أو تفاعلي (للمستقبل) |
| CondMDI، TransPhase، AIS | ملء الحركة بين وضعيتين (in-betweening) بدل الدمج الخطّي |
