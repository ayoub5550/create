# 05 · موشن تايبوغرافي (كلمات متحرّكة، 9:16 أو 16:9)

أسرع شكل للحقائق والأرقام والـ Shorts: كل كلمة تظهر لحظة نطقها، والكلمات المفتاحية تُلوَّن ويُرسم تحتها خط وتقفز،
والأرقام تعدّ تصاعدياً، والخلفية تتبدّل مع كل بطاقة.

```bash
python tools/voice/tts.py script.json            # علّم *الكلمات المفتاحية* في النص (صوت إنجليزي افتراضياً؛ القالب ما زال RTL)
python score.py                                  # (اختياري) بساط موسيقي + whoosh + pop على المفاتيح
python tools/build/kinetic.py <film_dir>         # kinetic.json → proj/index.html
```
- `kinetic.json`: `format` (`9:16` أو `16:9`)، و`palette` (أزواج [خلفية، لون مميّز] بتباين عالٍ)، و`vo` (البدايات)،
  و`cards` (سطر لكل بطاقة، مع `style`: `pop` أو `drop` أو `rise`، و`number` للعدّاد).
- العدّاد يبدأ عند الكلمة رقم `number.word`. اجعل الرقم مستديراً وصادقاً.
- إذا اختلف عدد الكلمات عن توقيتات الصوت تُوزَّع الكلمات بالتساوي ويظهر تحذير. أصلح النص (الرموز الملتصقة مثلاً).
- 9:16: اترك أعلى 250 بكسل وأسفل 300 بكسل فارغة (واجهة التطبيقات تغطّيها).
