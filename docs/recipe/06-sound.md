# 06 · الموسيقى والمؤثرات (كلها بالكود)

`tools/audio/sound.py` مكتبة numpy: عود بـ Karplus-Strong، وناي، ودفّ، وpad، وdrone، وجرس، ومطر ورعد وريح وصراصير
وعصافير وخطوات وحفر ورسم قلم وwhoosh وpop. ومعها `Score` الذي يضع الصوت في مكانه، ويخفض الموسيقى تحت السرد تلقائياً،
ويطبّع المستوى، ويطبع تقريراً بالمستويات.

## المقامات حسب الشعور (`MAQAM`، تدعم ربع التون)
| المقام | الإحساس | الاستعمال |
|---|---|---|
| حجاز | صحراء، رحلة، توتّر | البداية القاحلة، الدراما |
| نهاوند | ليل، حنين، حزن | الأزمة، الانتظار |
| كرد | شجن لطيف | الذكريات |
| صبا | أسى عميق | الفقد |
| بياتي | دفء شعبي | الحياة اليومية |
| راست | نُبل، «البيت»، حكي | الراوي، الختام الوقور |
| عجم | فرح، انفراج | الحلّ، النموّ، النهاية السعيدة |

قوس «البذرة»: حجاز ← نهاوند ← عجم ← عجم صاعد بالأربيجات. **غيّر المقام عند تحوّل القصة لا قبله.**

## المؤثرات
اربط كل مؤثر بلحظة من الفيلم (من `SEG` و`M.timeOf`) لا بتخمين: خطوة لكل نصف دورة مشي، و`dig()` مع ضربة المجرفة،
و`pop()` مع ظهور النبتة، و`scribble()` مع القلم أو اليد.

## المستويات (يطبعها `Score.render`)
- السرد ≈ ‎-22 dB RMS، والموسيقى وحدها بين الأسطر ≈ ‎-27 dB، والذروة أقلّ من ‎-1 dBFS.
- بعد التصدير: `verify.py` يقيس LUFS. المنصّات تطبّع إلى نحو ‎-14 LUFS، فالفيلم الهادئ لا بأس به.
- ملف واحد `mix.wav` بدل عدّة ملفات `<audio>` يعطي تحكّماً كاملاً بالمكساج.
