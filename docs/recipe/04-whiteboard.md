# 04 · لوح أبيض (يد ترسم)

مستوحى من التقنية المفتوحة `brandonvant/claude-skill-whiteboard-explainer` (MIT):
رسوم جاهزة تُكشف بقناع SVG متعرّج، ويد حقيقية تركب طرف الخط، وكاميرا تتنقّل على جدارية كبيرة.

## الخطوات
1. `script.json` ثم الصوت (`02-voice.md`).
2. **الرسوم**: عنصر واحد لكل فكرة، على أبيض نقيّ، بلا نصّ، وبأسلوب موحّد (`examples/sky/art.json` فيه STYLE جاهز).
   ```bash
   python tools/art/gen_art.py art.json proj/assets        # OPENAI_API_KEY، أو أيّ نموذج صور، أو SVG ترسمه أنت
   python tools/art/art_meta.py proj/assets art_meta.json  # حدود الحبر لكل صورة + سنّ القلم في اليد
   ```
   استعمل صورة اليد الجاهزة `examples/sky/art/hand.png`.
   **انظر إلى كل صورة**: لا نصوص مزيّفة، ولا حواف مقطوعة، والأسلوب متّسق.
3. **`board.json`**: المشاهد على شبكة (العربية: من العمود الأيمن)، ومواقع العناصر، والعناوين، والأفعال
   (`draw`، `label`، `cam`). الأوقات تُكتب بالكلمات: `"s2@7-0.1"` تعني 0.1 ث قبل الكلمة 7 من السطر s2.
4. `python tools/build/whiteboard.py <film_dir>` ثم `snap.py`.

## قواعد الإخراج
- كل عنصر **يكتمل** على كلمته المفتاحية. العنوان يبدأ مع نطق كلمته.
- اليد تظهر فقط أثناء الرسم. الكاميرا ثابتة بين الحركات، والحركة 0.8–1.0 ث مع `power2.inOut`.
- بين مشهدين بعيدين: تصغير في المنتصف (`"mid:s4,s5"`، zoom 0.42) ثم تكبير.
- الختام: `["cam", "mural", 2.0, t]` يسحب الكاميرا إلى الجدارية كلّها.
- العناوين العربية بخط الرقعة وتُكشف من اليمين إلى اليسار، واللاتينية بخط Caveat من اليسار إلى اليمين.
- `mix-blend-mode: multiply` على الرسوم يعمل فقط لأن `#camera` له لون الورق نفسه.
